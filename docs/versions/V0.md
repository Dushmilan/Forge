# V0 — Single-process executor

**Go concepts:** structs, methods, interfaces, error handling (`errors.New`,
`fmt.Errorf` with `%w`), the `testing` package.

**Why this version exists:** establish the core domain — a `Job` and an
`Executor` that runs it — with no concurrency, no persistence, and no HTTP.
Every later version evolves these types, so getting them small and clear now
pays off for the rest of the ladder.

## Deliverables

- `internal/job` package
  - `Job` struct: identifier, command, status.
  - `Status` named type with an `iota` enum and a `String()` method.
  - Validation for required fields, returning wrapped errors.
- `internal/executor` package
  - `Executor` type with a synchronous `Run` method.
  - Runs a job's command via `os/exec`, capturing output and exit status.
  - Returns a `Result` value plus an `error` on failure.
- `cmd/forge/main.go`
  - Accepts a command from the CLI, builds a `Job`, runs it, prints the result.
- `go.mod` with module `github.com/Dushmilan/Forge`, `go 1.22`.

## Test checklist

- A valid `Job` validates successfully; a job missing its command fails with a
  wrapped error.
- `Status.String()` returns the expected name for each status.
- `Executor.Run` executes a successful command and returns its stdout.
- `Executor.Run` returns an error when the command exits non-zero.
- `Executor.Run` returns an error for a command that does not exist.
- Tests use table-driven cases where multiple inputs share one behavior.

## Out of scope

Concurrency, persistence, HTTP, retries, timeouts/cancellation, sandboxing,
metrics, and any database or queue. Those arrive in later versions.
